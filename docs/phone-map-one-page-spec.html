Phone day view: one page for the list and the map

Spec for Brennan's OK · 8 Oct 2026 · built from the mocks agreed in this session · phone only, desktop unchanged

Goal. On a phone, the day's list and its map feel like one page, as they do on the computer. Opening the map grows it in place; it never leaves the day. exists = already in the code, reused. new = to build.

The list

3Map stripOnly the day's stops, framed on them. Pins in their legend colour and icon, with the order number. Today the strip paints them all dark. new
4Round map buttonOpens the map on this page. It no longer goes to the separate Map screen. new

Pins (list and map)

10The legend always holdsColour = type (purple food, teal things to do, dark logistics), icon = kind. The order number is a small tag. exists
112–3 pins touchingThey sit side by side, each with its own colour and icon. This replaces today's "2 · 4" pile on the strip. new
12Zoomed out, a crowdOne round pin with a count; its ring shows the colour mix. Tap it to zoom in. The chosen day's stops only merge with each other. new (the Map screen has no merging today)

Build: three pushes, each checked at phone width before it goes out

  • Push 1, pins: legend colours on the strip, side by side instead of piled, strip framed on the day (3, 10, 11).
  • Push 2, the map opens in place: full-screen map on the day page, every saved place with the rest muted, search pill, list button, bottom controls; the magnifier comes off (1, 4–8).
  • Push 3, days and crowds: tap a day to fit, tap again for the whole trip, count pins when zoomed out (9, 12).

Links that open the Map screen today (Plan my trip, Find, a shared pin) will open the day page with the map already open. The Map screen stays for the computer.

Two things to watch on your phone

  • The second tap to see the whole trip is easy to miss. If testers miss it, pinching out still gets them there.
  • Muted pins use the desktop's strength (about a quarter). Outdoors in sun that may be too faint; it's one number to change.
